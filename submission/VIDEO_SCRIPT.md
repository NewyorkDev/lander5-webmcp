Show the public URL and discover all eight site tools.

> The normal human interface and these eight tools share one state engine. This is a sandbox: no card, message, payment, or production appointment can be created.

> This is not a short-form demo. We mapped 57 production question concepts, including contact and access, home condition, recurring intent, appliances, move readiness, partial cleaning, bathroom configuration, add-ons, allergies, products, and scheduling. Conditional answers are supplied when relevant.

Show the visible telemetry and review.

> The consequential action fails closed. An agent cannot silently change the cleaning type or submit an outdated decision.

Click **Approve reservation request**, ask the agent to retry with confirmation, and show the sandbox result.
